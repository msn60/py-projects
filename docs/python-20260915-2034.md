# Python -> AI agent building — course roadmap

## Goal
Refresh Python (previously known, currently rusty) as fast and practically
as possible, then move into building AI agents, with some data analysis
along the way. Priority: job-market relevance, minimal detours, fast path
to agent building.

## High-level roadmap

| Phase | Focus | Rough timing |

| 1 | Python refresh — syntax, OOP, idioms | Week 1-2 |

# Setup

- Install python
- Install Python and Pylance extensions (from Microsoft)
- Create virtual environment
- Select interpreter in VSCode
- Setup format-on-save with ruff

```bash
python3 --version
# Python 3.12.3 -> already up to date, no need to upgrade

# On Ubuntu 24.04, venv module is separate from the main python package
sudo apt install python3.12-venv

python3 -m venv .venv
source .venv/bin/activate
# you must see something like this: (.venv) mehdi@mehdi-linux:~/projects/msn-codes$
```

**Why virtual environment?**
Keeps each project's packages isolated from the system Python and from
other projects. Avoids version conflicts (e.g. project A needs pandas 1.5,
project B needs pandas 2.0) and avoids breaking system-level packages
installed via apt.

**Select interpreter in VSCode** — done
- `Ctrl+Shift+P` -> `Python: Select Interpreter` -> chose the one inside `.venv`

**Final setup test** — done
- Created `test.py` with `print("hello")`, ran it, saw output in terminal

## Format-on-save with ruff

Python has no built-in formatter (unlike `gofmt` in Go). `ruff` is the
current standard: fast, combines linting + formatting, replaces older
tools like `black` + `flake8`.

```bash
# inside the activated .venv
pip install ruff
```

Install the `Ruff` VSCode extension (publisher: Astral Software).

Enable format-on-save — `Ctrl+Shift+P` -> `Preferences: Open User Settings (JSON)`
-> add:

```json
{
  "[python]": {
    "editor.defaultFormatter": "charliermarsh.ruff",
    "editor.formatOnSave": true
  }
}
```

Now `Ctrl+S` auto-formats the file, same feel as `gofmt`.
